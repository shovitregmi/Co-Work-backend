# Team Project Management System - Backend

##  Project Overview
This is the backend of a Team Project Management and Progress Tracking System built using Node.js, Express, and MongoDB.

It provides REST APIs for authentication, project management, task assignment, and progress tracking.

---

##  Tech Stack
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- bcryptjs
